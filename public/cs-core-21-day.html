Types of Keys
Trap: every candidate key is a super key, but not every super key is a candidate key (super key can have extra redundant attributes). Primary key = the chosen candidate key.
Relational Algebra
Know that SQL is a practical implementation of relational algebra — mapping SELECT→π, WHERE→σ, JOIN→⋈ helps you reason about query optimization questions.

Inner vs Outer Join
Trap: LEFT JOIN keeps all rows of the left table even with no match (NULLs on right) — interviewers love asking you to predict output row-count for a given join type + sample data.
Join vs Nested Query
Joins are generally faster (optimizer-friendly, single pass) vs correlated subqueries that can re-execute per outer row. Good follow-up: "how would you rewrite this subquery as a join?"

OA (Online Assessment) Specific Tips

Core-CS sections in OAs are almost always MCQ-based. Speed and pattern recognition matter more than deep derivation.

How core-CS MCQs are actually asked

Across Amazon, Flipkart GRiD, Juspay-style OAs and campus tests, the CS-core section is usually 10–20 MCQs pulled from a large bank covering exactly the topics above. Expect: numeric computation (waiting time, page faults, subnet count), "which statement is true/false," and output-prediction for a given SQL query or scheduling table.

High-yield MCQ topics

  • CPU scheduling — compute avg waiting/turnaround time
  • Page replacement — FIFO/LRU/Optimal trace + Belady's Anomaly
  • Deadlock — 4 conditions + Banker's Algorithm safe sequence
  • Normalization — identify highest normal form of a given table
  • SQL — predict output of JOIN / GROUP BY / subquery
  • OSI/TCP-IP layer mapping — "which layer does X belong to"
  • TCP 3-way handshake & TCP vs UDP

Time-management strategy

  • Core-CS MCQs: aim <45 sec/question — skip & return if stuck
  • Numeric ones (scheduling, paging) — draw the table fast on rough sheet
  • Don't overthink phrasing tricks — most MCQs test one fact, not reasoning chains
  • Revise the trap notes (red-bordered tips above) night before — they're the actual differentiators
